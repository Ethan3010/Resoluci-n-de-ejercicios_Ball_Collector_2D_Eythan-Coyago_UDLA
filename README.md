# Resoluci-n-de-ejercicios_Ball_Collector_2D_Eythan-Coyago_UDLA
Este proyecto es un prototipo interactivo en 2D desarrollado en Unity, El sistema de movimiento del jugador está programado utilizando Scripting Tradicional en C#. La lógica para la recolección de las esferas y actualización del contador fue implementada usando el sistema de Visual Scripting.
